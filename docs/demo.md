# DEALMIND — 90 Second Demo Script

This follows the "Killer Demo" from the product blueprint.

1. **New Quote** — Go to *Negotiate*, pick **Apex Industrial Supplies**, product
   "Industrial Bearings", quantity 5000, quoted price ₹96. Click **Analyze**.

2. **Memory Retrieval** — The Negotiation Brief appears instantly, citing N past
   negotiations, a historical price range, and the tactic that has worked best
   with this vendor. Scroll to the **Evidence Panel** at the bottom of the
   brief and point out the actual memory sentences it's reasoning from.

3. **Strategy** — Point out the four key numbers: recommended target range,
   opening counter, recommended tactic, and payment terms suggestion — all
   computed from history, not guessed.

4. **Live Negotiation** — In the *Negotiation Workspace* chat, type a vendor
   reply, e.g. `"₹91 is the lowest we can go"`. DEALMIND suggests a specific
   counter-offer with reasoning tied to this vendor's history.

5. **Save Outcome** — Fill in the final price / terms / tactic and hit
   **Save Outcome & Learn**. This writes new memory to Hindsight and
   recomputes the vendor's behavioral profile.

6. **See It Learn** — Go to that vendor's *Vendor Profile* page — the
   "What DEALMIND Learned" section now includes the new experience. Start a
   **second** negotiation with the same vendor — the brief updates to reflect
   what was just learned, with higher confidence.

That's the whole thesis in 90 seconds: **Remember → Recall → Reason →
Negotiate → Learn → do better next time.**
